Revisão teórica das tecnologias

1 - O que é lógica de programação

É o conseito estudado para desenvolver algoritimos e a lógica por traz dos códigos e programas de softwares


2 - Porque podemos comparar lógica de programação com uma receita de bolo

Porque você tem que seguir uma sequencia de passos para resolver um problema com se fosse uma receita para achar a solução


3 - Oque é a linguagem C e para que serve

C é um linguagem compilada usada principalmente para softwares embarcados, sistemas operacionais e softwares de alto nivel


4 - Oque é a linguagem JavaScript e para que serve

JavaScript é uma linguagem de programação usada principalmente para mexer com a interface de sites como animação mas também pode ser usada para o backand usando Node.js


5 - Oque é um I.D.E em programação

É a sigla de Integrated Development Environment ou Ambiente de Desenvolvimento Integrado que é um ambiente de trabalho onde reune tudo que necessario para um programador em um só lugar


6 - Qual a diferença de uma linguagem interpretada para uma linguagem compilada

A linguagem compilada passa por um processo que transforma oque o programador escreveu em código de maquina antes da execução enquantoa linguagem interpretada transforma o código em inguagem de máquina em tempo de execução


7 - Quais os impactos positivos e negativos a I.A vem causando para você

A ia trouxe vantagens e desvantagem para mim por exemplo se alguem saber usala pode alavancar seu potencial nos estudos como pedir explicações ou exercios a ela por outra lado ela traz algums problemas como uso por empresas que dificulta encontrar ou se manter em trabalhos, já que a I.A ja faz diversas coisas
